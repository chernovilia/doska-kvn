# Бизнес-модель Доска/КВН

Canonical-документ по типам аккаунтов, монетизации и алгоритму ранкинга.  
Все ссылки на код — из репозиториев `doska-kvn` (фронт) и `doska-kvn-api` (бэк).

---

## Типы аккаунтов

```
User
├── Личный (personal)     — по умолчанию, приватный профиль
└── Бизнес (business)     — публичный профиль /u/[slug]
    ├── Мастер (master)   — услуги: электрик, репетитор, грузчик
    └── Магазин (shop)    — товары/услуги от юрлица или ИП
```

**Правила**:
- Один пользователь = один активный тип
- Переключение Личный ↔ Бизнес → заполнение бизнес-профиля
- Смена подтипа Мастер ↔ Магазин → тип меняется, история сохраняется
- Каждое объявление хранит **снапшот** `authorType` на момент публикации — не меняется потом
- При смене на Личный бизнес-профиль **архивируется** (не удаляется), можно вернуться

**Публичность**:
- Личный: **приватный** по умолчанию, есть тумблер видимости
- Бизнес: **всегда публичный** — рейтинг, отзывы, объявления видны всем

**Реальные двойные роли** (Мастер+Магазин одновременно):
- В MVP не поддерживаем
- Если реальный кейс — регистрируется два аккаунта на разные телефоны
- Позже, как премиум-фича — «Второе направление» +500 ₽/мес

## Разовые опции продвижения объявлений

Работают для **любого типа юзера** (Личный / Мастер / Магазин).  
Одно объявление можно комбинировать (Срочно + Поднять сразу).

| Опция | Цена | Что делает | Срок |
|---|---|---|---|
| 🔼 **Поднять** | 39 ₽ | Возвращает наверх ленты (`Ad.boostedAt = now()`, +0.15 к score на 24 часа) | 24 часа |
| 🔥 **Срочно** | 79 ₽ | Оранжевая плашка + `Ad.promoLevel = 2` | 3 дня |
| 💎 **VIP** | 199 ₽ | Плашка VIP + гарантия первых 3 позиций (`Ad.promoLevel = 4`) | 7 дней |

Хранится в таблице `AdPromo`. По истечении `expiresAt` статус сбрасывается кроном.

## Подписки для Бизнеса

Активируются на **весь аккаунт**, не на конкретное объявление. Оплата ежемесячно через ЮKassa.

| Тариф | Цена | Возможности |
|---|---|---|
| 🌱 **Старт** | **0 ₽/мес** | Публичный бизнес-профиль, витрина, рейтинг, отзывы, **15 объявлений одновременно** |
| 🏆 **ТОП** | **500 ₽/мес** | Всё из Старт + `autoPromoLevel = 1` (все объявления автобустятся), значок TOP на профиле и карточках, **аналитика** (просмотры, звонки, сообщения, конверсии), **50 объявлений** |
| 💠 **Премиум** | **1 200 ₽/мес** | Всё из ТОП + **показ во всех городах агломерации** (у КВН = все 3 города), значок «Партнёр», приоритетная поддержка, **100 объявлений** |

Хранится в таблицах `Tier` (справочник) + `Subscription` (активные подписки).

**Правила подписок**:
- Trial: 7 дней ТОП бесплатно для новых бизнес-аккаунтов
- **Возврат**: только для месячной, в первые 3 дня
- **Годовая оплата** (задел): −20% при оплате за год
- **Grace period**: 3 дня после истечения — статус активен, потом флаг `subscriptionExpired = true`
- После grace: премиум-функции отключаются, все объявления теряют автобуст, значки исчезают

**Задел на будущее** (не в MVP):
- **Мультирегион** — 2 400 ₽/мес — Премиум-КВН + любой соседний регион
- **Пакеты объявлений без подписки** — 10 постов за 300 ₽ — для сезонного бизнеса
- **Расширенный аналитический пакет** — +500 ₽ — экспорт данных, глубокие отчёты

## Система «звёзд» (gamification, без денег)

Начисляются за активность, тратятся на бесплатные бонусы. Реальные деньги не связаны.

**Начисления**:
- **10 ⭐** — за первое опубликованное объявление
- **5 ⭐** — за первую сделку (подтверждение обеими сторонами)
- **3 ⭐** — за каждый оставленный отзыв
- **20 ⭐** — за первую покупку тарифа
- **1 ⭐** — за приглашённого пользователя, который опубликовал объявление

**Траты**:
- **50 ⭐** = 1× «Поднять» (эквивалент 39 ₽)
- **100 ⭐** = 1× «Срочно» (эквивалент 79 ₽)
- **200 ⭐** = 1× «VIP» (эквивалент 199 ₽)

Хранится в таблице `Wallet` (balance) + `WalletTransaction` (журнал).

## Промо-коды

Таблица `Promocode` + `PromocodeUse`.

**Применимо к**:
- Тариф (`tier:top`, `tier:premium`)
- Разовые опции (`ad_promo:vip`, `ad_promo:urgent`)
- Баннер (`banner:home_slide`)

**Варианты скидок**:
- Процент от суммы (`discountPercent`)
- Фиксированная скидка в копейках (`discountAmount`)
- Ограничение по числу использований (`maxUses`)
- Ограничение по сроку (`usableUntil`)

Использование: реферальная программа, сезонные акции, компенсация проблем.

## Алгоритм ранкинга объявлений

### Формула

Каждое объявление получает **score** от 0 до 1. Лента сортируется по убыванию.

```
score =
  freshness  × 0.35   +   Свежесть
  promoLevel × 0.30   +   Продвижение
  trust      × 0.15   +   Доверие автору
  quality    × 0.10   +   Качество объявления
  engagement × 0.10       Вовлечённость
```

### Компоненты

**Свежесть** (0..1):
```
freshness = max(0, 1 - hours_since_created / (24 × 10))
```
За 10 дней падает до 0.

**Продвижение** (0..1):
```
promoLevel = level / 4   где level ∈ {0, 1, 2, 3, 4}
```
- 0 обычное → 0
- 1 Поднято / автобуст ТОП → 0.25
- 2 Срочно → 0.5
- 3 VIP → 0.75
- 4 премиум-TOP или подписки Премиум → 1.0

**Доверие** (0..1):
```
trust = (verified ? 0.5 : 0) + author.rating / 10
```
- Новый аккаунт: 0.0
- Верифицированный с 4.5★: 0.95

**Качество** (0..1):
```
quality = (has_photos ? 0.5 : 0) + (description.length > 50 ? 0.5 : 0)
```

**Вовлечённость** (0..1):
```
engagement =
  min(1, views / 100) × 0.5 +
  min(1, writes / 10) × 0.5
```

### Правила поверх формулы

- **VIP top-3**: первые 3 позиции резервируются под `promoLevel = 4`
- **Anti-repetition**: одному автору не более 3 позиций в первых 10 карточках
- **Анти-соседство**: между объявлениями одного автора минимум 1 чужое
- **Boost 24h**: если `boostedAt` не старше 24 часов — +0.15 к финальному score
- **Архив**: объявления старше 30 дней в основной ленте не показываются (только по прямой ссылке)

### Настройка через feature flags

Все веса и константы хранятся в `Setting`:

```
ranking.weight.freshness      = 0.35
ranking.weight.promo          = 0.30
ranking.weight.trust          = 0.15
ranking.weight.quality        = 0.10
ranking.weight.engagement     = 0.10
ranking.freshness_days        = 10
ranking.vip_top_positions     = 3
ranking.same_author_max_top10 = 3
ranking.boost_bonus           = 0.15
ranking.archive_days          = 30
```

Меняется через админку без деплоя.

### Эволюция

**MVP (сейчас)**: чистая формула.

**Через 3 месяца** (накопятся `AdView`, `Favorite`):
- Content-based персонализация: буст объявлений похожего на историю юзера типа
- Уже готов метод `getSimilarAds` в API

**Через полгода**:
- Collaborative filtering (LightFM/implicit)
- Отдельный ML-микросервис

## Feature flags управления монетизацией

Все хранятся в таблице `Setting`, меняются через админку.

```
# Общий выключатель
payments.enabled              false   → ВСЯ монетизация выключена

# Разовые опции
payments.ad_promos            false   → показывать кнопки «Поднять/Срочно/VIP»
payments.ad_promo.bump.price  3900    → в копейках
payments.ad_promo.urgent.price 7900
payments.ad_promo.vip.price   19900

# Подписки
payments.subscriptions        false   → показывать тарифы Мастер/Магазин
payments.tier.top.price       50000
payments.tier.premium.price   120000
payments.free_trial_days      7
payments.yearly_discount      0.20
payments.grace_period_days    3

# Баннеры
payments.banners              false
payments.banners.home_slide.price   50000   → 500₽/день
payments.banners.feed_inline.price  20000

# Кошелёк
payments.wallet.stars.enabled false
payments.wallet.stars_rate.bump   50
payments.wallet.stars_rate.urgent 100
payments.wallet.stars_rate.vip    200
```

**На старте**:
```
payments.enabled = false
```
Всё скрыто в UI. Схема лежит в БД, ждёт активации.

## Экономика — прикидка на первые 3 месяца

**Точка окупаемости инфраструктуры** (~2 500 ₽/мес):
- **5 подписок ТОП** = 2 500 ₽/мес — покрытие
- **10 подписок ТОП + 20 разовых VIP** = 5 000 + 4 000 = **9 000 ₽/мес**
- **20 подписок ТОП + 5 Премиум + 30 разовых** = 10 000 + 6 000 + 5 000 = **21 000 ₽/мес**

**Ориентир на 6 месяцев**: **30 000-40 000 ₽/мес** при 1 000 DAU и правильно поставленной активации.

**Стратегия активации**:
- Первые 2 месяца после запуска — всё бесплатно
- Постепенно включаем feature flags: сначала разовые опции, потом подписки
- Trial 7 дней ТОП — для первых 20 мастеров даём бесплатно 30 дней (как якорь)

## Что закладываем в схему сейчас

Все таблицы — в новой миграции Prisma:

- `UserType` enum: `personal | master | shop`
- `BusinessProfile` (переименовать из `Shop`) с полем `kind`
- `Ad`: `authorType` (снапшот), `authorSnapshot` (Json), `promoLevel`, `boostedAt`, `promoExpiresAt`, счётчики
- `Tier` — справочник тарифов
- `Subscription` — активные подписки
- `AdPromo` — разовые опции
- `Banner` — реклама
- `Payment` — журнал платежей ЮKassa
- `Wallet` + `WalletTransaction` — звёзды
- `Promocode` + `PromocodeUse` — промо-коды
- `Favorite`, `AdView`, `Report`, `AnalyticsEvent` — базовые сущности
- `Setting`: наполняется всеми `payments.*` и `ranking.*` флагами

Всё это добавляется как одна миграция, применяется через `db push` в проде.  
UI ничего не меняет — тарифы и опции скрыты до `payments.enabled = true`.
