Ошибка внесена в 1.0.1 вместе с превью для соцсетей: проверка входа «переехала» с `GET /ads/:id` на `og.jpg` | Проверка входа возвращена на `GET /ads/:id`. ## Проверено — замечаний нет

- **Доступ**: все действия с объявлением (правка, архив, продление, подъём, автоподнятие, удаление) проверяют владельца; админские — только `ADMIN_EMAILS`; `wipe` на проде закрыт.
- **Публичные ответы**: почта и телефон не уходят ни в ленте, ни на странице продавца, ни по своему адресу `/u/…`; страницы заблокированных и не заполнивших профиль не открываются.
- **Превью `og.jpg`**: берёт только фото из нашего хранилища и только у опубликованных объявлений.
- **Настройки из админки** (контакты, соседние города, тексты окна установки): длина ограничена, на сайте выводятся текстом; ссылки Telegram/ВК собираются из имени, произвольный адрес подставить нельзя.
- **Сайт**: нет вставки сырого HTML; внешние ссылки с `rel`; старых цветов (фиолетовый и т. п.) не осталось.
- **Телефон 375 px**: главная, объявление, профиль, сообщения, избранное, помощь, продвижение, админка — без горизонтальной прокрутки, все кнопки-иконки подписаны, у картинок есть `alt`, ошибок в консоли нет.
- **Короткие ссылки**: `/ad/<8 символов>` и старая полная ссылка открывают одно объявление; новый id выдаётся только со свободным началом; несуществующая — «не найдено».

## Что осталось

| Приоритет | Что | Почему не сейчас |
|---|---|---|
| 🟠 | **Переход на Next 15** (с React 19). В Next 14 остаются известные уязвимости класса «отказ в обслуживании» для серверных компонентов; исправления для 14-й ветки больше не выходят. То, что у нас не используется (Server Actions, middleware, rewrites, оптимизатор картинок), нас не затрагивает | Крупное обновление: нужно пройти весь сайт заново. Делать отдельным релизом сразу после запуска |
| 🟡 | NestJS 10 → 11/12: 5 предупреждений средней важности (`file-type` при разборе загруженных файлов, `@nestjs/core`) | Тоже смена основной версии; загрузки у нас ограничены по размеру и только для вошедших |
| 🟡 | Метрики приложения (`/app/open`, `/app/event`) принимают события без входа — счётчики можно накрутить (в пределах общего лимита запросов) | Это статистика, на работу сайта не влияет |
| 🟡 | Список «Мои объявления» в профиле запрашивается дважды при открытии | Лишний запрос, не ошибка |

Не проверяется без настоящих устройств (в [PRODUCTION.md](PRODUCTION.md), п. 1): приход пушей, счётчик на иконке, установка на iPhone, превью в ВК и Telegram, письма о сроках.
