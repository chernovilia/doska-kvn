# Документация Доска/КВН

Вся документация проекта — сайта и API — в этой папке.

| Документ | Когда открывать |
|---|---|
| [PRODUCTION.md](PRODUCTION.md) | **Готовность к продакшену**: что готово, что сделать до запуска и сразу после, что отложено |
| [STATE.md](STATE.md) | Что сейчас работает в проде, что не сделано, технический долг, переменные окружения, локальный запуск |
| [STRUCTURE.md](STRUCTURE.md) | Как устроен код: репозитории, папки, компоненты, модули API, модели данных, основные сценарии |
| [API.md](API.md) | Все эндпоинты API с параметрами и лимитами |
| [DESIGN.md](DESIGN.md) | Стиль интерфейса: цвета, кнопки, чипы, блоки, письма — что использовать и что нельзя |
| [ADMIN.md](ADMIN.md) | Админка: что умеет сейчас (в начале) и целевой дизайн с ролями |
| [RANKING-AND-PROMO.md](RANKING-AND-PROMO.md) | Как сортируется лента и работает «Поднять» (раздел 0 — текущая формула), план VIP и монетизации |
| [TESTING.md](TESTING.md) | Что проверять после каждого обновления, общий прогон, найденные при тестировании проблемы |
| [AUDIT-2026-09-29.md](AUDIT-2026-09-29.md) | Аудит: что исправлено, что проверено, что осталось по приоритету |
| [ROADMAP.md](ROADMAP.md) | Что делаем дальше и в каком порядке, расходы |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Исходная архитектура; в начале — таблица расхождений с реализацией |
| [BUSINESS-MODEL.md](BUSINESS-MODEL.md) | Типы аккаунтов и тарифы (целевой дизайн) |

**Правило**: меняешь поведение — обновляй STATE.md; добавляешь эндпоинт — API.md и README в `doska-kvn-api`; меняешь устройство кода — STRUCTURE.md; меняешь внешний вид — сверяйся с DESIGN.md.
