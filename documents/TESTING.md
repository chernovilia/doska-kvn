# Ручное тестирование

Как пользоваться:
1. После каждого обновления сначала пройти раздел **«Что проверить после этого обновления»** — там только новое и исправленное.
2. Перед заметным релизом — весь **«Общий прогон»**.
3. Нашли проблему — записать в **«Найдено при тестировании»** (номер, что сделали, что ожидали, скриншот), после исправления — перенести в журнал.

Нужно: телефон (Safari/Chrome и браузер ВК) и компьютер; два аккаунта — продавец и покупатель (вторую почту удобно открывать в режиме инкогнито); доступ в админку.

## Общий прогон

### Вход и профиль
- [ ] Вход по коду с почты: код приходит, вход работает
- [ ] `…/login?returnTo=/profile` → после входа возвращает в профиль
- [ ] Новый аккаунт → онбординг: имя, город, способ связи; после — «Аккаунт создан»
- [ ] Профиль: метрики, вкладки «Объявления / Отзывы / Настройки», редактирование данных
- [ ] Через 20+ минут на открытой странице действия (публикация, админка) работают без обновления страницы
- [ ] Выход — снова гость

- [ ] Шапка с поиском и нижнее меню закреплены при прокрутке
- [ ] Выбор места «Все города» / город

- [ ] Поиск строчными находит слово с заглавной
- [ ] Пустой раздел: «Пока пусто», кнопка подачи у гостя ведёт на вход
- [ ] Карточки быстро показывают фото (миниатюры)

### Подача объявления
- [ ] Гость на «+» → вход

- [ ] Характеристики для раздела; у афиши — дата и место
- [ ] Загрузка нескольких фото сразу, удаление фото

- [ ] Автопубликация выкл → «Отправлено на проверку», в профиле плашка «На проверке»

### Страница объявления
- [ ] Галерея листается, счётчик фото
- [ ] Цена, путь по категориям, характеристики, продавец
- [ ] «Позвонить» (если у продавца телефон), «Написать»

- [ ] «Написать» → диалог, сообщения доходят без обновления страницы
- [ ] Письмо о первом непрочитанном
- [ ] iPhone (Safari и ВК): тап на поле ввода — экран не прыгает, поле над клавиатурой
- [ ] Отзыв появляется по правилу (см. п. 11), оба могут оценить друг друга
- [ ] Отзыв на странице продавца и в профиле, рейтинг пересчитан

### Избранное, продавец
- [ ] Сердечко → «Избранное» в нижнем меню; убрать — пропадает
- [ ] «Все объявления продавца» → страница продавца с объявлениями и отзывами

### Уведомления и письма
- [ ] Колокольчик: счётчик, список, тап ведёт куда нужно, «Прочитать все»
- [ ] Письма: новое сообщение, новый отзыв, опубликовано / отклонено / скрыто / удалено / снова в ленте, ответ поддержки; у админа — «на модерации», новое обращение. Кнопка в письме ведёт на нужную страницу

### Помощь
- [ ] Профиль → Настройки → «Помощь» → обращение; админу уведомление
- [ ] Ответ из админки приходит пользователю, переписка продолжается

### Админка
- [ ] Обзор: очереди и метрики, «Ваш IP глазами сервера» совпадает с 2ip.ru
- [ ] Объявления: поиск, фильтры; одобрить, отклонить с причиной, скрыть, вернуть, удалить
- [ ] Жалобы: разобрать
- [ ] Поддержка: ответить, закрыть
- [ ] Пользователи: поиск, блокировка (заблокированный не может публиковать и писать), разблокировка
- [ ] Отзывы: удаление пересчитывает рейтинг
- [ ] Настройки: изменить значение — сохраняется и не сбрасывается после деплоя

- [ ] Браузер ВК: главная, объявление, подача, чат, профиль
- [ ] Ничего не уезжает вбок, модалки и шторки не перекрываются панелями браузера
