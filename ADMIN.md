# Админка Доска/КВН

Панель управления для владельца и сотрудников.

> **Это целевой дизайн, а не описание текущей админки.** Что реально работает сейчас — в [STATE.md](STATE.md), раздел «Админка».
> Отличия реализации от этого документа:
> - Вход — по email-коду (SMS нет). Доступ даёт `User.role` = `admin`/`owner` или email в env `ADMIN_EMAILS`. Таблицы `AdminUser` нет.
> - Роли `moderator` / `content` / `support` в enum есть, но права по ним не разграничены — `AdminGuard` пускает только admin/owner.
> - Реализованы вкладки: Обзор, Пользователи, Объявления (с модерацией), Настройки (тумблер автопубликации).

## Доступ

- URL: `доска-квн.рф/admin/**`
- Вход: обычный (через ту же авторизацию по SMS/email), но требует роли `moderator` и выше
- Роли задаются вручную через таблицу `AdminUser` — сначала владельцем в базе, потом через саму админку

## Роли и права

| Роль | Модерация | Пользователи | Объявления | Слайды | Настройки | Логи | Финансы |
|---|---|---|---|---|---|---|---|
| **owner** | ✅ | ✅ полный | ✅ полный | ✅ | ✅ | ✅ | ✅ |
| **admin** | ✅ | ✅ полный | ✅ полный | ✅ | ✅ | ✅ | ✅ |
| **moderator** | ✅ | 👁 read + блок | 👁 read | ❌ | ❌ | ❌ | ❌ |
| **content** | ❌ | ❌ | 👁 read | ✅ | ❌ | ❌ | ❌ |
| **support** | ❌ | 👁 read | 👁 read | ❌ | ❌ | ❌ | ❌ |

- ✅ — полный доступ
- 👁 — только просмотр (или ограниченные действия)
- ❌ — нет доступа

## Разделы админки

### 1. Дашборд `/admin`
Что видно:
- **Метрики за 24 часа**: новые пользователи, объявления, сообщения, показы, звонки, отчёты
- **Модерация**: очередь pending + количество жалоб
- **Топ разделов** с активностью
- **Последние события** — 20 недавних AdminAction

Для кого: все роли (у каждого свой набор виджетов)

### 2. Модерация `/admin/moderation`
Что видно:
- **Очередь pending** — карточки объявлений, ожидающих ручной проверки
- Причина попадания в очередь: rate limit / blacklist / phash / LLM / жалоба
- Фильтр по разделу, городу, дате
- **Действия**: Одобрить · Отклонить (с причиной) · Скрыть · Заблокировать автора

Плюс отдельная вкладка **Жалобы** — `Report` от пользователей.

Для кого: moderator, admin, owner

### 3. Пользователи `/admin/users`
- Поиск: телефон, e-mail, ФИО, ID, VK-id
- Фильтры: тип (обычный/магазин), верифицирован, заблокирован, дата регистрации
- Карточка пользователя:
  - Инфо + история входов + Trusted Devices
  - Объявления, чаты, жалобы, отзывы
  - Действия: **Верифицировать · Заблокировать · Разблокировать · Изменить роль · Удалить** (только owner)

Для кого: admin/owner — полный, moderator/support — просмотр + блок

### 4. Объявления `/admin/ads`
- Все объявления во всех статусах
- Поиск, фильтры по городу/разделу/автору/статусу/дате
- Редактирование, удаление, продвижение (TOP/Срочно бесплатно)
- Массовые действия

Для кого: admin/owner — полный, все остальные — просмотр

### 5. Магазины `/admin/shops`
- Список магазинных аккаунтов
- Заявки на верификацию — «Проверен через Подслушано»
- Управление отображением на карточке магазина
- Смена тарифа (когда включим)

Для кого: admin/owner + content

### 6. Афиша `/admin/events`
- Только объявления раздела `events`
- Управление организаторами (публичный аккаунт с бейджем)
- Планирование постов на главной

Для кого: content, admin, owner

### 7. Слайды главной `/admin/slides`
- Редактор `HERO_SLIDES` — визуальный вместо файла
- Порядок drag'n'drop
- Расписание: показать с … до …
- Предпросмотр в реальном времени

Для кого: content, admin, owner

### 8. Регионы и категории `/admin/dictionaries`
- **Регионы**: добавить, отключить, назначить соседей
- **Города**: добавить, привязать к региону
- **Категории**: редактор `CATEGORY_GROUPS` — группы и подкатегории

Для кого: admin, owner

### 9. Контент `/admin/content`
- `/terms`, `/privacy`, `/help`, `/pwa-install`
- Markdown-редактор + предпросмотр
- Версионирование (можно откатить)

Для кого: content, admin, owner

### 10. Настройки `/admin/settings`
- Feature flags из таблицы `Setting` (visual editor)
- Лимиты: rate limit, размер фото, длина описания
- Модерация: включить LLM / выбрать провайдера / промпт
- Тарифы и цены (когда включим)

Для кого: admin, owner

### 11. Аналитика `/admin/analytics`
- Дашборд: DAU/MAU, воронка регистрации, воронка публикации
- Топ поисковых запросов
- Отток и ретеншн
- Экспорт в CSV

Для кого: admin, owner

### 12. Финансы `/admin/finance` (после включения платежей)
- Транзакции, платежи, возвраты
- Отчёты для налоговой
- Выплаты магазинам (если появятся)

Для кого: owner + admin

### 13. Логи `/admin/logs`
- `AdminAction` — что делал каждый админ
- `AnalyticsEvent` — сырые события
- Фильтр по админу, действию, дате
- Immutable: нельзя удалить или отредактировать

Для кого: owner (для аудита)

### 14. Модерация сообщений `/admin/chats` (после этапа 4)
- Просмотр переписок по жалобам
- Не показываем нормальные чаты — только те, на которые пожаловались

Для кого: support, moderator, admin, owner

## Технически

### Реализация

- **Фаза 1**: `/admin` — отдельные страницы в том же Next.js-приложении
  - Guard в middleware проверяет `AdminUser.role`
  - При отсутствии роли → 404 (не 403, чтобы не палить наличие админки)
- **Фаза 2**: если разрастётся — отдельное приложение `admin.доска-квн.рф` (SPA на React)
  - Общая БД, общая авторизация

### UI-принципы

- Никакой Framer Motion, лёгкая тема — админка это утилита
- Тайлаунд + серые тона, без градиентов
- Все таблицы с сортировкой, фильтром, пагинацией
- Массовые действия через чекбоксы
- Каждое опасное действие требует подтверждения
- Каждое действие пишется в `AdminAction`

### Аудит-лог

Для каждого действия в БД:

```
AdminAction {
  id
  adminId          — кто
  action           — 'ad.approve' | 'user.block' | 'setting.update' | ...
  targetKind       — 'ad' | 'user' | 'setting' | ...
  targetId
  notes            — что именно изменил
  prevValue        — старое значение (для отката)
  newValue         — новое значение
  ip
  userAgent
  at
}
```

Никогда не удаляем. Хранится вечно для юр-обязательств.

## Дорога развития

**Фаза 1 (запуск с MVP)** — только минимум для одного админа-владельца:
- Модерация + Жалобы
- Пользователи (просмотр + блок)
- Объявления (просмотр + удаление)
- Слайды главной
- Настройки (rate limit, blacklist)

**Фаза 2 (когда 500+ пользователей и появятся сотрудники)**:
- Все роли, разграничение доступа
- Магазины
- Аналитика
- Аудит-лог

**Фаза 3 (когда пойдут платежи)**:
- Финансы
- Отчёты для налоговой

**Фаза 4 (масштаб)**:
- Отдельный сабдомен `admin.доска-квн.рф`
- Bulk-операции
- API-доступ для будущих интеграций
