# Стиль интерфейса

Один стиль на весь сайт, админку и письма: **тёмный текст, белые карточки на светло-сером фоне и один оранжевый акцент**. Оранжевый — это «сюда нажать» и «выбрано». Других акцентных цветов нет: ни фиолетового, ни синего для кнопок и ссылок.

Цвета заданы в `tailwind.config.js`, общие классы — в `app/globals.css` (`@layer components`).

---

## 1. Цвета

### Акцент — `accent` (оранжевый)

| Токен | HEX | Где |
|---|---|---|
| `accent-50` | `#fff7ed` | Фон выбранного (`.chip-on`), подсветка блока, строка при наведении |
| `accent-100` | `#ffedd5` | Фон иконки-кружка, мягкий бейдж |
| `accent-200` | `#fed7aa` | Рамка подсвеченного блока |
| `accent-300` | `#fdba74` | Рамка `.pill-on`, кольцо текущего шага |
| `accent-400` | `#fb923c` | Рамка `.chip-on`, **кольцо фокуса полей** (`focus:ring-accent-400`) |
| `accent-500` | `#f97316` | **Главная кнопка**, «+», счётчики непрочитанного, свои сообщения в чате, слеш в логотипе |
| `accent-600` | `#ea580c` | Главная кнопка при наведении, иконки-акценты |
| `accent-700` | `#c2410c` | **Текст-акцент и ссылки** (контраст 5:1 на белом), текст в `.chip-on` |
| `accent-800/900` | `#9a3412` / `#7c2d12` | Тёмный текст на оранжевом фоне |

### Текст — `ink`

| Токен | HEX | Где |
|---|---|---|
| `ink-900` | `#0f172a` | Заголовки, цены, основной текст, логотип |
| `ink-800` | `#1e293b` | Иконки в шапке, текст второго уровня |
| `ink-700` | `#334155` | Обычный текст в блоках, подписи полей |
| `ink-600` | `#475569` | Пояснения на цветном фоне |
| `ink-500` | `#64748b` | Подписи, даты, «3 часа назад», подсказки |
| `ink-400` | `#94a3b8` | Заглушки, неактивное |
| `ink-300` | `#cbd5e1` | Разделители на тёмном |

### Фон и рамки
- Страница — `bg-slate-50`; карточки и шапки — `bg-white`.
- Рамка карточки — `ring-1 ring-black/5`, поля ввода — `ring-1 ring-black/10`.
- Серые кнопки и чипы — `bg-slate-100`, при наведении `bg-slate-200`.
- Разделители — `border-slate-100` / `divide-slate-100`.

### Статусы (только для смысла, не для украшения)

| Смысл | Цвета | Пример |
|---|---|---|
| Успех, опубликовано | `emerald` (50 фон, 700 текст) | «Опубликовано», «Бесплатно» |
| Ожидание, на проверке | `amber` | «На проверке», звёзды рейтинга |
| Ошибка, отклонено, удалить | `rose` | «Отклонено», «Удалить объявление», ошибки форм |
| Архив, нейтральное | `slate` | «В архиве», «Скоро» |

### Плитки разделов
Каждому разделу — свой пастельный цвет (`data/categories.js`, поле `tile`): `bg-{цвет}-100 text-{цвет}-800`. Используются amber, sky, emerald, orange, blue, lime, pink, yellow, teal, cyan, rose. **Фиолетовые (violet, purple, indigo, fuchsia) не используем.**

### Запрещено
- Классы `brand-*` (палитры больше нет — класс молча не сработает), `indigo-*`, `violet-*`, `purple-*`, `fuchsia-*`.
- Новые акцентные цвета для кнопок и ссылок.
- HEX-цвета в коде, кроме писем (там Tailwind нет — см. раздел 6).

## 2. Шрифт и текст
- Системный шрифт (`font-sans`: system-ui, -apple-system, Segoe UI, Roboto).
- Заголовок страницы — `text-lg font-extrabold`; крупный — `text-xl md:text-2xl font-extrabold`.
- Цена — `font-black` / `font-extrabold`, `text-ink-900`.
- Основной текст — `text-sm` / `text-[15px]`; подписи — `text-[12px]`–`text-[13px] text-ink-500`; мелкие бейджи — `text-[11px] font-bold`.
- Надзаголовок (например, «ПОДАТЬ ОБЪЯВЛЕНИЕ · ШАГ 1 ИЗ 7») — `text-xs uppercase tracking-wide font-bold text-accent-700`.
- Поля ввода — не меньше `text-base` (16 px), иначе iPhone увеличивает страницу при фокусе.

## 3. Кнопки

| Вид | Классы | Когда |
|---|---|---|
| **Главная** | `bg-accent-500 hover:bg-accent-600 text-white font-bold` + `rounded-2xl` (в формах, `h-11`) или `rounded-full` (компактные) | Одно главное действие на экране: «Далее», «Опубликовать», «Продвинуть», «Найти», «Оценить» |
| Неактивная главная | `disabled:bg-slate-300` | Шаг не заполнен |
| Второстепенная | `.btn-outline` — белая, серая рамка 2 px, `font-bold` | «Назад», «Редактировать», «Продано», «+ Добавить» |
| Опасная | `bg-white border-2 border-rose-100 text-rose-700 hover:bg-rose-50` | «Удалить объявление» |
| Текстовая | `text-accent-700 font-semibold` (иногда `underline`) | «Моя страница продавца», «Написать в поддержку» |
| Иконка в шапке | `HeaderIconButton` — `w-10 h-10 rounded-full hover:bg-slate-100` | Назад, колокольчик, выход |
| Иконка на карточке | белый кружок с тенью (`IconButton` в `AdCard`) | Сердечко, ссылка, карандаш, корзина |

Высота: основные — `h-11` (44 px, удобно пальцем), компактные — `h-8`–`h-9`.

## 4. Выбор и фильтры

| Класс | Вид | Где |
|---|---|---|
| `.chip` | Серая плашка `bg-slate-100`, `h-9`, `rounded-full` | Варианты в формах, вкладки профиля, города |
| `.chip-on` | + светло-оранжевый фон, оранжевая рамка, оранжевый текст | Выбранный вариант |
| `.chip-sm` | `h-8`, `text-[13px]` | Подвкладки (Активные · На проверке · …), шаблоны причин |
| `.pill` | Белая плашка с тенью, `h-10` | Управление над лентой: сортировка, «Цена», «Фильтры» |
| `.pill-on` | + светло-оранжевый фон и рамка | Включённый фильтр |

Выделенная вкладка (например, «Продвижение») — `.chip` + `bg-accent-50 text-accent-700 ring-1 ring-accent-200`.
Полосы чипов, которые не влезают, **прокручиваются по горизонтали** (`flex overflow-x-auto no-scrollbar`), а не сжимаются в сетку.

## 5. Блоки и раскладка

- **Карточка-блок**: `rounded-2xl bg-white ring-1 ring-black/5 shadow-card p-4`.
- **Подсвеченный блок** (важное, «скоро в архив»): `rounded-2xl bg-accent-50 ring-1 ring-accent-200 p-4`.
- **Плашка статуса** над объявлением: цвет по таблице статусов, `rounded-2xl ring-1 px-4 py-3`.
- **Шапка страницы** — только `PageHeader` (`components/PageHeader.jsx`): закреплена (`sticky top-0`), белая, `h-14`, «назад» слева, действия справа. На главной — `Header` с поиском, тоже закреплён.
- **Нижнее меню** — `BottomNav` на всех страницах телефона; «+» — оранжевый круг `accent-500`.
- **Окна** — `Modal`: на телефоне выезжают снизу (`rounded-t-3xl`), шапка окна закреплена.
- **Отступы**: по краям экрана телефона `px-4` (16 px); между блоками `space-y-3`–`space-y-4`; в сетке карточек `gap-3`.
- **Скругления**: блоки и кнопки в формах `rounded-2xl`, чипы и маленькие кнопки `rounded-full`, фото в списках `rounded-xl`.
- **Тени**: `shadow-card` — карточки, `shadow-soft` — всплывающее (окна, «+»).
- **Загрузка**: скелетоны (`AdCardSkeleton`, `bg-slate-100 animate-pulse`), а не текст «Загрузка…»; внутри кнопок и фото — спиннер `Loader2 animate-spin`.
- **Иконки** — только lucide-react: `w-4 h-4` в кнопках, `w-5 h-5` в шапках и блоках.

### Чат
- Свои сообщения — `bg-accent-500 text-white`, чужие и ответы поддержки — `bg-white ring-1 ring-black/5`.
- Приглашение «Оцените собеседника» — полоса `bg-amber-50` над полем ввода.

### Аватары
`components/Avatar.jsx`: своё фото, готовый (12 пастельных, без фиолетовых) или буква на оранжевом круге.

## 6. Письма
В письмах нет Tailwind — цвета HEX (`doska-kvn-api/src/auth/email-template.ts`):
- кнопка — фон `#f97316`, белый текст, `border-radius:12px`;
- код входа — `#ea580c`; ссылки — `#c2410c`;
- слеш в логотипе — `#f97316`; текст — `#0f172a`, подписи — `#64748b`.

Цвет панели браузера на телефоне (`themeColor` в `app/layout.jsx`) — белый `#ffffff`, как шапка.

---

## 7. Как добавлять новое
1. Сначала ищем готовое: `PageHeader`, `Modal`, `.chip`, `.pill`, `.btn-outline`, `AdCard`, `Avatar`, `OwnerAdActions`.
2. Главная кнопка на экране — одна и оранжевая. Остальные — `.btn-outline` или текстовые.
3. Цвет из раздела 1; если нужен новый — сначала дописать сюда.
4. Проверить на ширине 375 px: ничего не уезжает вбок, текст не переносится по одной букве.
