## ✅ Что работает в проде

### Инфраструктура
- **Фронт**: Next.js 14 (App Router) на Amvera, домен `доска-квн.рф` (через прокси Cloudflare)
- **Бэк**: NestJS 10 + Prisma 5 на Amvera, поддомен `api.доска-квн.рф`
- **БД**: PostgreSQL 17 (Amvera CNPG, внутренний host `amvera-chernovilia-cnpg-doska-kvn-db-rw`)
- **Медиа**: Timeweb S3 (`doska-kvn-main`, 10 GB с автоапгрейдом, path-style, ACL public-read)
- **Почта**: Unisender Go (транзакционный API, `noreply@доска-квн.рф`, DKIM/SPF/DMARC настроены)

### Авторизация
- Email + 6-значный код (`POST /v1/auth/email/request` → `/verify`)
- Rate-limit: `EMAIL_CODE_INTERVAL_SEC=60`, максимум `EMAIL_CODE_MAX_ATTEMPTS=5`
- JWT: access 15 мин + refresh 90 дней в httpOnly cookies (`Domain=.xn----7sbhf4acwc1a.xn--p1ai`)
- Ротация refresh при каждом `/auth/refresh`, blacklist через `RefreshToken.revokedAt`
- Клиент: `AuthProvider` в `app/layout.jsx` — один контекст для всех потребителей
- SessionStorage-кеш `doska-kvn:me` подставляется после монтирования (первый рендер как на сервере, иначе ломается гидрация)
- `?returnTo=` принимает только внутренние пути (`safeReturnTo` в `lib/site.js`)

### Онбординг
- Страница `/onboarding` (не модалка: во встроенных браузерах вроде ВК панели перекрывают фиксированные окна). `<AuthOnboardingGate>` уводит туда с любой страницы, пока `me.onboardedAt === null`, и возвращает на `returnTo`
- Поля: имя, город КВН (чипы), способ связи (сообщения / телефон + номер), уведомления на email. «О себе» — в настройках
- Submit → `PATCH /v1/me` с `markOnboarded: true, agreeTerms: true`, тост «Аккаунт создан»

### Сообщения
- Модели `Conversation` (одна на пару объявление + покупатель; снапшот заголовка и фото, переживает удаление объявления) и `Message`
- API `/v1/conversations`: открыть по объявлению, список, непрочитанные, сообщения с `?after=`, отправка (1–2000 символов). Только участники, чужой диалог — 404
- `/messages`: список + диалог, опрос новых сообщений раз в 5 с (на свёрнутой вкладке пауза), значок непрочитанных в шапке и нижнем меню (опрос раз в 30 с)
- Письмо получателю через Unisender — только на первое непрочитанное в диалоге и при `notifyEmail`
- Телефон продавца: `GET /v1/ads/:id/contact` (только вошедшим, 30/час) и только если продавец выбрал связь по телефону

### Профиль (`/profile`)
- Аватарка (буква имени или загруженное фото)
- Метрики: рейтинг, отзывы, сделки, активные объявления
- Тип аккаунта: пока только «Личный», рядом иконка ✎ disabled (бизнес — потом)
- Вкладки: **Объявления**, **Отзывы** (пусто, заглушка), **Настройки**
- Настройки: `SettingsEditModal` для 4 kind-ов (personal, phone, city, notifications), каждый → `PATCH /me`

### Лента и разделы
- 11 разделов (`data/categories.js` ↔ `SECTION_IDS` в API): Авто, Недвижимость, Работа, Услуги, Электроника, Дом и дача, Одежда и обувь, Детское, Животные, Хобби и спорт, Афиша. Иконки lucide, цвет плитки — там же
- «Отдам даром» — виртуальный раздел `free`: цена 0 в разделах с вещами и животными (`FREE_FROM_SECTIONS`), подать в него нельзя
- Подгруппы раздела (`categoryGroup`): у «Работы» — Вакансии и Резюме, у вакансий зарплата от/до (`price` + `priceTo`, `priceSuffix: '₽/мес'`)
- Шапка (белая, не липкая): логотип, место текстом с булавкой, колокольчик, «Войти»; поиск с пристыкованной кнопкой «Найти»
- Под шапкой плитки разделов с короткими подписями (`short`), первая — «Ещё»: каталог всех разделов с подгруппами (`CatalogSheet`, его же открывают «Разделы» в нижнем меню). У выбранного раздела ниже лента подгрупп
- Сортировка — иконка с нативным списком, цена — плашка «Цена ▾»
- Общие плашки в `globals.css`: `.chip` / `.chip-on` (выбор: серая / светлая оранжевая с рамкой), `.pill` / `.pill-on` (управление над лентой), `.btn-outline` (второстепенные кнопки и круглые иконки «назад»)
- Фильтры в URL: `?section=&group=&q=&sort=&pmin=&pmax=`. Меняются через `history.pushState` — Next синхронизирует `useSearchParams` без запроса страницы; «назад» возвращает прошлый фильтр
- По умолчанию «Все объявления» места по ранкингу; на телефоне лента без подвала; сортировка «Сначала новые / Дешевле / Дороже»
- `formatPrice`: вилка «40 000 – 60 000 ₽/мес», «от …» у вакансии без верхней границы, цена 0 — «Даром» (вещи), «Бесплатно» (афиша), иначе «Договорная»
- Старые объявления с разделом `market` открываются, но в разделы ленты не попадают — удалить через админку

### Карточка и страница объявления
- `AdCard`: квадратное фото, под ним цена, заголовок, «город · время»; счётчик фото, если их больше одного; без фото — иконка раздела. Вся карточка — `<Link>`, кнопки (избранное, ссылка, удалить) лежат рядом со ссылкой, не внутри. Вилка зарплаты в карточке короткая: «40–60 тыс. ₽/мес» (`formatPrice(ad, { compact: true })`)
- `/ad/[id]`: галерея листается пальцем (scroll-snap) со счётчиком «1 / 3», на компьютере — стрелки и миниатюры; блок «цена → заголовок → раздел › подгруппа › категория → место, время, просмотры»
- На телефоне снизу закреплена панель «Позвонить / Написать» вместо нижнего меню; у автора — нижнее меню и панель владельца
- Просмотры: `POST /v1/ads/:id/view` при открытии страницы, один раз в сутки на зрителя (гость — по `doska-kvn:sid` в localStorage), автор не считается

### Характеристики
- Набор полей по разделу и подгруппе — `data/attributes.js` (авто: марка, модель, год, пробег, двигатель, коробка, топливо, привод; жильё: комнаты, площадь, этаж, этажность; вакансии: график, занятость, опыт; услуги: где работаете, опыт; техника, одежда, животные…). Менять можно без миграций: хранится в `Ad.attributes` (JSONB)
- Подача: шаг «Характеристики» появляется, только если у подгруппы есть поля; всё необязательно, числа проверяются на диапазон. У афиши там же обязательные дата и время, у афиши и жилья — адрес
- Страница объявления — таблица «Характеристики»; карточка — строка-сводка («2019 · 85 000 км · Механика», «2-к · 54 м² · 3/9 эт.»)
- Фильтров по характеристикам в ленте пока нет

### Объявления
- `GET /v1/ads` с фильтрами (place, section, group, chip, search, priceMin, priceMax) + сортировка top / recent / cheap / expensive. Место, которого нет в БД, даёт пустой список
- `GET /v1/ads/:id` с автором + фото
- `POST /v1/ads` — создание с фото (`photoUrls[]`), автопубликация по `Setting['moderation.autoApprove']`
- `DELETE /v1/ads/:id` — владелец удаляет своё (проверка `authorId`); на `/ad/[id]` автор видит панель владельца со статусом и кнопкой «Удалить»
- `POST /v1/ads/:id/bump` — бесплатный подъём опубликованного объявления (`boostedAt = now` → +0.15 к score на 24 ч), пауза `Setting['ranking.bump_cooldown_hours']` = 72; кнопка «Поднять» в панели владельца и под карточками в `/profile`
- `GET /v1/me/ads` — все свои (approved / pending / rejected / archived)
- Публичная страница `/ad/[id]` с Open Graph
- `PostAdModal`: 6 шагов (город → раздел → категория → описание → фото → превью), финиш → редирект на `/ad/[id]`. Поле цены зависит от раздела: зарплата от/до у вакансий, «₽ в месяц / за сутки» у аренды

### Фото
- `POST /v1/uploads/ad-photo` — multipart, sharp: авто-EXIF, resize до 1600px, WebP q80
- До 6 фото на объявление, до 12 MB на исходник
- Хранятся в `ads/YYYY/MM/<uuid>.webp`, ссылка вставляется в `AdPhoto`

### SEO
- `/sitemap.xml` (`app/sitemap.js`): главная, города запущенных регионов, `/terms`, `/privacy`, все одобренные объявления из `GET /v1/ads/sitemap`; revalidate раз в час
- `/robots.txt` (`app/robots.js`): закрыты `/admin`, `/profile`, `/messages`, `/login`

### Юридические страницы
- `/terms` — Условия использования
- `/privacy` — Политика конфиденциальности (152-ФЗ, хранение в РФ)

### Защита от спама (`@nestjs/throttler`, глобальный guard)
- Глобально: 300 запросов/мин, 5000/час, 50 000/сутки — только от долбёжки (мобильные операторы держат много абонентов за одним IP)
- `POST /v1/ads`: 5/час, 20/сутки
- `POST /v1/uploads/ad-photo`: 30/час, 100/сутки
- Чаты: отправка 20/мин и 300/час; опрос (`messages`, `unread-count`) — 120/мин
- Ключ лимита (`AppThrottlerGuard`): `userId` из валидного access-токена, для гостей — `CF-Connecting-IP`, иначе `req.ip`
- Лимиты хранятся в памяти процесса — сбрасываются при рестарте API
- Гость, обращающийся к API в обход Cloudflare (по amvera.io-домену), может подставить свой `CF-Connecting-IP`. Критичные эндпоинты (`POST /ads`, загрузка фото) требуют авторизации и считаются по `userId`, так что это не обход

### Админка (`/admin`)
- Доступ: `AdminGuard` — email в `ADMIN_EMAILS` env или `role='admin'|'owner'`
- Вкладка **Обзор**: счётчики (юзеры, объявления, фото, кошельки, токены, платежи…) + красная кнопка «Стереть всё»
- Вкладка **Пользователи**: пагинация, удаление с cascade
- Вкладка **Объявления**: фильтр по статусу (все/pending/approved/rejected/archived), автор в строке, ✓ Одобрить / ✕ Отклонить / удалить
- Клик по строке объявления → `ModerationModal`: галерея фото, описание, цена, автор с контактами, кнопки Одобрить / Отклонить / Удалить (`GET /v1/admin/ads/:id`)
- Вкладка **Настройки**: тумблер автомодерации (`Setting['moderation.autoApprove']`)

## 🔴 Технический долг

- **Схема БД через `prisma db push` при старте** (без `--accept-data-loss`): добавления применяются сами, а изменение, удаляющее данные, остановит старт API с ошибкой. Такие изменения выкатывать вручную. Полноценные миграции (`migrate deploy`) отложены: 21.09 он падал на Amvera CNPG с `permission denied to create database`, проверить переход вне прода пока негде (нужен локальный или staging Postgres). Папка `prisma/migrations/20260921000000_init` устарела и не используется.
- **Осиротевшие фото в S3**: если пользователь загрузил фото в `PostAdModal`, но не опубликовал объявление, файлы остаются в бакете. Нужна периодическая чистка: объекты старше суток без записи в `AdPhoto`. (Фото удалённых объявлений уже чистятся — `S3ClientService.deleteByUrls`.)
- **HTTPS держится только на Cloudflare**: у Amvera нет сертификата для `доска-квн.рф` и `api.доска-квн.рф` (проверено 27.09: на наш домен её ingress отвечает TLS alert 40). Выключить прокси Cloudflare нельзя, пока Amvera не выпустит сертификаты. Выключать стоит: прокси расшифровывает трафик за границей (трансграничная передача ПДн — противоречит `/privacy` и 152-ФЗ) и есть риск замедления Cloudflare в РФ. Порядок: домены + сертификаты в Amvera → записи в Cloudflare на «DNS only» → проверка
- **Вложенные кнопки в `AdCard`**: карточка — `<button>`, внутри кнопки сердечка, «поделиться», «удалить». Невалидный HTML, React ругается. Исправить при переделке карточки
- **Sentry / логи**: только console.log. Runtime ошибки в проде не видно.
- **Аналитика**: нет метрики.
- **Email-верификация**: DKIM в Unisender настроен, но нет автоматической проверки (если что-то сломается, узнаешь только когда коды перестанут доходить).

## 🚀 Что запускать локально

⚠️ Из-за двоеточия в имени папки `доска:квн` (в `PATH` это разделитель) `npm run build` / `npx next` не находят бинарник. Запускай напрямую: `node node_modules/next/dist/bin/next dev` (или `build`).

```bash
# Бэк
cd doska-kvn-api
npm install
# нужен DATABASE_URL к любому Postgres (dev-контейнер / удалённый)
npx prisma db push --skip-generate
npm run start:dev

# Фронт
cd доска:квн
npm install
# .env.local: NEXT_PUBLIC_API_URL=http://localhost:3000/v1
npm run dev
```

Локальную БД можно сеятить включив `SEED_ON_STARTUP=true` — создаст регионы, города, тарифы и демо-юзера с объявлениями.
